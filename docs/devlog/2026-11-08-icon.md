# 2026-11-08: The app icon

- Looked at three rounds of icon ideas. Picked a gold coin stamped with a V, floating over midnight water with its reflection, under a moon and stars, with a faint digital grid on the water: markets, currency, the V, and a virtual touch. Chose the "deep night" sky: heavy blue with a faint green line at the horizon, like just after dusk.
- Made the real icon files: the app icon, Android's two-layer adaptive icon (checked on a round mask), a one-color version for Android's themed icons, the splash screen, and a small web icon. The icon's source and the script that draws it are kept in `frontend/assets/icon-source`.
- Set the app's name to "Vagora" and its ID to `com.vagora.app` for now. The standard is to base the ID on a domain we own; vagora.com is parked for sale and vagora.app is taken, so the final ID gets confirmed when we pick a domain, before any store release.
- Next: the production setup (Firebase, Neon, Vercel), then the first APK.
