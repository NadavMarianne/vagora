# 0001: Project name: vagora

**Date:** 2026-10-29 **Status:** Accepted

## Decision
The project is called **vagora**, short for "virtual agora" (the agora was the ancient Greek marketplace).

## Why
Short, easy to type and say, unique, and the meaning still fits the idea.

## Alternatives considered
`virtuagora` (clearer meaning, but long and hard to pronounce), `vitumarket`, `agorix`, `bazaar`, `micro-market`.
